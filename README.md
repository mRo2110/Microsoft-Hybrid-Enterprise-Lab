# Microsoft-Hybrid-Enterprise-Lab
Homelab project for building and documenting a Windows-based enterprise IT infrastructure.
# Installation von SRV-DC01

## Virtuelle Maschine

Für die Laborumgebung wurde eine virtuelle Maschine mit VMware Workstation erstellt.

### Konfiguration

- Betriebssystem: Windows Server 2022
- Servername: SRV-DC01
- IP-Adresse: 192.168.10.10
- Arbeitsspeicher: 4 GB

## Netzwerkkonfiguration

Der Server verwendet eine statische IPv4-Adresse.
